# Хедж-бот: арбитраж между биржами

Сканирует котировки нескольких бирж, находит монеты, которые дешевле купить
на одной бирже и дороже продать на другой (с учётом сети/контракта монеты),
и считает реальный Net% после торговых комиссий и комиссии вывода.

## Команды

- `cmd/transferbot` — бумажный сканер. Ордеров и выводов не делает, только
  считает и пишет отчёт. `go run ./cmd/transferbot` или `--minutes 10` для
  опроса несколько раз подряд.
- `cmd/tradebot` — полуавтоматический режим для пары gate/bitget. Фильтрует
  кандидатов по риску (живучесть спреда, комиссия вывода — факт, а не
  оценка, буфер на проскальзывание, cooldown по монете) и перед каждым
  необратимым шагом (покупка/вывод/продажа) спрашивает подтверждение.
  Без `--execute` — чистая бумага.
- `cmd/gateconvert`, `cmd/bitgetconvert` — проверка баланса и аварийная
  продажа монеты на Gate/Bitget по рынку. Без `-execute` только показывают
  баланс.
- `cmd/tlog` — длительный опрос gate/bitget с записью находок в текстовый
  лог до заданного времени.

## Настройка

Ключи API — в `.env` (не коммитится):

```
GATE_API_KEY=...
GATE_API_SECRET=...
BITGET_API_KEY=...
BITGET_API_SECRET=...
BITGET_API_PASSPHRASE=...
```

Параметры стратегии и риска — в `configs/*.yaml`:

- `notional_usd` — размер сделки для расчёта Net% (должен совпадать с
  реальным размером, иначе Net% будет завышен/занижен).
- `persist_polls` — сколько опросов подряд должен держаться спред, прежде
  чем `tradebot` предложит сделку.
- `max_notional_per_trade_usd`, `cooldown_minutes`, `slippage_buffer_pct`,
  `require_fee_known` — риск-лимиты живой торговли.

## Важно перед реальными деньгами

- API-ключи должны быть привязаны к вашему публичному IP на обеих биржах
  (`curl -s https://api.ipify.org`, сверить с настройками ключа).
- На маленьком нотионале (~$100) фиксированная комиссия вывода часто
  съедает весь спред — это не баг, а экономика; `tradebot` корректно не
  найдёт сделку в таком случае.
- Поля API-запросов (ордера, вывод) соответствуют публичной документации
  Gate/Bitget на момент написания — биржи меняют API, первый живой прогон
  делайте на минимальном размере под присмотром, не в фоне.
